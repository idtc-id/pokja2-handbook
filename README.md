# Pokja 2 IDTC — Handbook

**Data · Teknologi · Implementasi** — *Membuktikan melalui implementasi nyata.*

Buku pegangan kerja Pokja 2 Indonesia Digital Twin Community (IDTC).

## Target Pokja 2

1. **Pilot project Digital Twin** yang nyata dan terukur.
2. **Dokumentasi dan model replikasi** yang bisa dipakai instansi/lokasi lain.
